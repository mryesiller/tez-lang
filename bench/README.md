# bench/

Measurement, not opinion. Filled in during **Phase 0** (tokens) and **Phase 3** (TezBench).

- `tokens/` — tokenizer set (`tokenizers.toml`) and the token-cost tool
- `tasks/` — TezBench tasks, each with tests and contracts
- `ts/` — TypeScript twins of every example/task
- `results/` — versioned JSON results; never overwritten

See skills `measure-tokens` and `run-tezbench`.

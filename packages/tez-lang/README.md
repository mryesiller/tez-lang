# tez-lang

**Tez** — a fast, verified programming language that small LLMs write well and browsers run natively (WasmGC).

This package is reserved for the WebAssembly build of the Tez compiler. It is **pre-alpha and contains no code yet**.

Project, design and roadmap: <https://github.com/mryesiller/tez-lang>
